# Boot animation

`bootanimation.zip` is generated by `generate.sh` (ImageMagick 6 and the Roboto font from `external/roboto-fonts`, Apache-2.0); it holds no external artwork. Regenerate it from the source tree root, inside the build container:

```sh
vendor/perleos/bootanimation/generate.sh vendor/perleos/bootanimation/bootanimation.zip
```

Frames are 1600x600 at 30 fps, centred on black. `part0` plays once (the pearl lights up, then the name fades in); `part1` loops until boot completes (the pearl's glow breathes).
