# Boot animation

`bootanimation.zip` is generated by `generate.sh` with ImageMagick 6 and Space Grotesk from [`../fonts`](../fonts) (OFL-1.1); it holds no external artwork. Regenerate it from the source tree root, inside the build container:

```sh
vendor/perleos/bootanimation/generate.sh vendor/perleos/bootanimation/bootanimation.zip
```

The logo is the PerleOS wordmark: "Perle" in Space Grotesk Bold, the pearl as the O, "S" in Space Grotesk Light, in `#F4F1EC` on black. The pearl uses the logo's gradient (`#FFFFFF`, `#E3DAF3`, `#A9B7DC`) and top-left highlight; a soft `#E3DAF3` halo surrounds it.

Frames are 1600x900 at 30 fps, centred on a black screen. `part0` plays once (the pearl and its halo light up, then the letters fade in); `part1` loops until boot completes (the halo breathes).
