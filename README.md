# vendor/perleos

PerleOS product configuration on top of `vendor/lineage`. Device products inherit `config/overlays.mk` before the LineageOS common makefile and `config/common.mk` after it:

```make
$(call inherit-product, vendor/perleos/config/overlays.mk)
$(call inherit-product, vendor/lineage/config/common_full_tablet_wifionly.mk)
$(call inherit-product, vendor/perleos/config/common.mk)
```

The first overlay directories take priority, and `vendor/perleos/overlay` replaces resources that `vendor/lineage` also overlays (default wallpaper, lock screen clock font). Without `config/overlays.mk`, no PerleOS overlay applies.

`config/common.mk` adds microG and F-Droid (`vendor/microg`) and sets `ro.perleos.version` (`<major>.<minor>-<UTC build date>`) in the `product` build properties. It also installs:

- the Space Grotesk font ([`fonts`](fonts)), the default system font, with a Roboto option in Wallpaper & style > Font;
- the boot animation ([`bootanimation`](bootanimation)) and the default wallpaper ([`wallpaper`](wallpaper)), both generated by scripts in this repository.
