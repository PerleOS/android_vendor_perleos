# vendor/perleos

PerleOS product configuration on top of `vendor/lineage`. Device products inherit `config/overlays.mk` before the LineageOS common makefile and `config/common.mk` after it:

```make
$(call inherit-product, vendor/perleos/config/overlays.mk)
$(call inherit-product, vendor/lineage/config/common_full_tablet_wifionly.mk)
$(call inherit-product, vendor/perleos/config/common.mk)
```

The first overlay directories take priority, and `vendor/perleos/overlay` replaces resources that `vendor/lineage` also overlays (default wallpaper). Without `config/overlays.mk`, none of the resources in `overlay` apply.

`config/common.mk` adds microG and F-Droid (`vendor/microg`) and sets the PerleOS version, `<major>.<minor>-<LineageOS version suffix>` (e.g. `0.1-20261113-UNOFFICIAL-j706f`), as `ro.perleos.version` in the `product` build properties and as `ro.lineage.display.version`, which Settings shows under "PerleOS version". It also installs:

- the boot animation ([`bootanimation`](bootanimation)) and the default wallpaper ([`wallpaper`](wallpaper)), both generated by scripts in this repository.
- `PerleOSLauncher3Overlay` and `PerleOSSystemUIOverlay` ([`overlays`](overlays)), which make the backgrounds of recents and of the notification shade translucent: without window blur the stock colors are opaque. The shade overlay needs the `ScrimController` change of the PerleOS `frameworks/base`; without it the colors are drawn opaque. The brightness slider background uses the same color.
